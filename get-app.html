Install it on Android

  1. Tap Download for Android above.
  2. When it finishes, tap the file (or open Files then Downloads).
  3. If Android asks, tap Settings and turn on Allow from this source, then go back.
  4. Tap Install. If Play Protect warns about an unknown app, tap More details then Install anyway.
  5. Open App Finder from your home screen.
